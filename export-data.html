Export Hungry Birds POS data

This reads the database already on this computer and this browser and saves it as one file you can import into the new POS. It does not change or delete anything.

Open this page from the same address as the original POS (for example your-pos-site/export-data.html). A browser keeps a separate database for every website, so opening the file from disk or from a different address will show an empty result.

If the result is empty, sign in to the original POS once in this browser first — then run this again.
